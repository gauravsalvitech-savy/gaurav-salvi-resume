## 🌟 Key Features

- 📄 **1-Click Clean PDF / Print Export**: Strips interactive control bars and produces a crisp, ATS-compliant, recruiter-ready printed resume.
- ✏️ **Live In-Browser Edit Mode**: Toggle the **Edit Mode** button to customize phone numbers, email addresses, bullet points, skills, and projects in real-time. Changes are auto-saved in your browser (`localStorage`).
- 🎨 **Multiple Themes**:
  - **Cyber Dark** (Default modern dark mode)
  - **Clean White** (Minimalist light mode)
  - **Executive Slate** (Corporate navy/slate)
  - **Emerald Forest** (Tech emerald)
- 🗂️ **Dynamic Layouts**: Switch seamlessly between **2-Column Modern Grid** and **Classic Single-Column** document format.
- 📋 **Copy to Clipboard**: Quick 1-click copy icons for email and phone numbers.
- 📱 **Fully Responsive**: Optimized for desktop monitors, tablets, and mobile screens.

## 🚀 How to Open & Use

### Option 1: Direct in Browser
Simply double-click `index.html` or open it with Google Chrome, Microsoft Edge, Firefox, or Safari.

### Option 2: Live Server / Dev Server (Optional)
If you have Python installed:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

---

## 🖨️ How to Save / Export as PDF

1. Click the **"Export PDF / Print"** button in the top action bar (or press `Ctrl + P` / `Cmd + P`).
2. Set the Destination to **"Save as PDF"**.
3. Under **More settings**:
   - Check **"Background graphics"**.
   - Set **Margins** to **"Default"** or **"Minimum"**.
4. Click **Save**.
